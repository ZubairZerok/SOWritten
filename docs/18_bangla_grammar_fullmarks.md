# ১৮ · বাংলা ব্যাকরণ (১০ নম্বর): ফুল মার্কস প্যাক, স্ট্রেস-টেস্টের পর

> **পরীক্ষা:** ২৭ নভেম্বর ২০২৬ · প্রশ্ন ৭ · ১০ নম্বর · সময় ৮–১০ মিনিট
> **এই ফাইল কেন:** ২২ নভেম্বরের অডিটে আগের বাংলা প্রস্তুতিতে (doc 09, doc 17, বুকলেট-পরিশিষ্ট, কুইজ) তথ্যগত ভুল, পরস্পরবিরোধী নিয়ম আর বড় কভারেজ-ঘাটতি পাওয়া গেছে। শেষে সংশোধনী লগ দেওয়া আছে। এই ফাইলটিই এখন বাংলা ব্যাকরণের মূল উৎস।

## ০. স্ট্রেস-টেস্টের রায়

**আগের প্রস্তুতি দিয়ে পূর্ণ নম্বর নিশ্চিত ছিল না।** কারণগুলো:

1. **সিলেবাসের বাইরের প্রশ্ন।** জুন ২০২৬-এর প্রশ্নে (একমাত্র যে প্রশ্নপত্র এই সিলেবাসে হয়েছে) ৫টির মধ্যে ২টি প্রশ্ন সিলেবাসের বাইরে থেকে এসেছিল: **বাচ্য** ("…আশা করা যায় না" কোন বাচ্য?) আর **স্ত্রীবাচক শব্দ** ("কুহক"-এর স্ত্রীবাচক)। অর্থাৎ ১০-এর মধ্যে ৪ নম্বর। আগের প্রস্তুতিতে এ দুটির একটি লাইনও ছিল না। → নিচে §৪.১০ ও §৪.১১।
2. **দুই ব্যাকরণের সংঘাত।** NCTB ২০২৬ বইয়ে কারক ৬টি: কর্তা, কর্ম, করণ, **অপাদান**, অধিকরণ, **সম্বন্ধ**। এখানে **সম্প্রদান কারক নেই** (বই পৃষ্ঠা ৯৫, নিজে যাচাই করা)। পরীক্ষক সাধারণত প্রথাগত ব্যাকরণ মানেন, যেখানে সম্প্রদান আছে এবং সম্বন্ধ কারক নয়। doc 09-এ সম্প্রদান ছিল, doc 17-এ ছিল না, কিন্তু কোথাও দুই মতের কথা বলা হয়নি। → §২-এ "দুই মত মিলিয়ে উত্তর" লেখার নিয়ম।
3. **ভুল তথ্য।** "অপমানিত" শব্দকে অশুদ্ধ বলা হয়েছিল (আসলে শুদ্ধ, অশুদ্ধ রূপ হলো "অপমান হয়েছে")। রেফ-নিয়মের উদাহরণ ভুল ছিল ("অর্জন নয় অর্জন", "বর্ণ্না")। "শ্রেণি"-কে অতৎসম বলা হয়েছিল। "দিপালি" বানান ভুল ছিল। "সমীচীন → সমীচীন" (একই শব্দ দুই পাশে) ছিল। "৫০টি বাক্যশুদ্ধি" বলা হলেও ছিল ২৫টি, "Golden 30" বলা হলেও ছিল ১২টি। পূর্ণ তালিকা §৭-এ।
4. **অনুশীলনের ধরন মেলে না।** পরীক্ষায় লিখে উত্তর দিতে হয় (ব্যাসবাক্য, কারক-বিভক্তি, বাক্যে প্রয়োগ), কিন্তু অনুশীলন ছিল শুধু MCQ। MCQ-তে চিনতে পারলেও খাতায় নিজে লিখতে গেলে আটকে যাওয়া সম্ভব।
5. **লক্ষ্য ছিল ৭/১০** (doc 09)। পূর্ণ নম্বরের পরিকল্পনা ছিল না।

**এখন:** নিচের প্যাকটি ৯টি সিলেবাস-টপিক আর ব্লুপ্রিন্টে আসা ২টি বাইরের টপিক কভার করে। এতে উত্তরের ফরম্যাট, দুই মত মিলিয়ে উত্তর লেখার কৌশল আর ৩টি মক প্রশ্নপত্র আছে। **তবে কোনো প্রস্তুতিই ১০০% গ্যারান্টি দিতে পারে না।** প্রশ্নকর্তা যেকোনো অপরিচিত বাগধারা বা শব্দ দিতে পারেন। বাস্তবসম্মত লক্ষ্য **৯–১০**। সেটা নিশ্চিত হবে যদি §৫-এর ৩টি মক খাতায় লিখে দেন আর ভুলগুলো আবার করেন।

## ২. ২ নম্বরের পূর্ণ উত্তর: প্রতিটি টপিকের ফর্মুলা

| টপিক | পূর্ণ উত্তরে যা থাকতে হবে | নমুনা |
|---|---|---|
| সমাস | ব্যাসবাক্য **+** সমাসের নাম **+** উপবিভাগ | চক্রপাণি = চক্র পাণিতে যার — **ব্যধিকরণ বহুব্রীহি** সমাস |
| সন্ধি | বিচ্ছেদ **+** সন্ধির ধরন (চাইলে নিয়মও) | উদ্ধার = উৎ + হার (ব্যঞ্জনসন্ধি: ৎ + হ = দ্ধ) |
| কারক | কারক **+** বিভক্তি (প্রথাগত নাম) **+** কারণ এক শব্দে | তিলে = **অপাদান কারকে ৭মী বিভক্তি** (উৎস) |
| বাগধারা | অর্থ **+** একটি বাক্য | অগস্ত্য যাত্রা = চিরদিনের জন্য প্রস্থান। *বিদেশে গিয়ে তার যেন অগস্ত্য যাত্রা হলো।* |
| প্রবাদের নিহিতার্থ | আক্ষরিক মানে নয়, **শিক্ষাটা** লিখুন **+** প্রয়োগ | "বজ্র আঁটুনি ফস্কা গেরো" = বাইরে কঠোর নিয়ম, ভেতরে ফাঁক। ব্যাংকে কাগুজে নীতিমালা কঠোর, অথচ ঋণখেলাপি থামে না। |
| এক কথায় | শুধু শব্দটি, সঠিক বানানে | যা পূর্বে দেখা যায়নি — **অদৃষ্টপূর্ব** |
| বানান | শুদ্ধ রূপ **+** নিয়ম এক লাইনে | **মুহূর্ত** (হ-এ দীর্ঘ ঊ-কার) |
| বাক্যশুদ্ধি | পুরো শুদ্ধ বাক্য **+** ভুলের ধরন | তিনি **সস্ত্রীক** এসেছেন। (স = সহ; 'স্ব' = নিজ) |
| শব্দজোড় | দুটির অর্থ **+** প্রতিটির ছোট বাক্য | কুল = বংশ; কূল = তীর। *সে উচ্চ কুলের সন্তান। নদীর কূলে বাড়ি।* |
| বাচ্য | বাচ্যের নাম **+** কারণ | **ভাববাচ্য**: ক্রিয়ার ভাবই প্রধান, কর্তা গৌণ (ষষ্ঠী/দ্বারা) |
| লিঙ্গ | শুধু শব্দটি (বানান ঠিক রেখে) | কুহক → **কুহকিনী** |

### ⚖️ দুই মত মিলিয়ে উত্তর (NCTB ২০২৬ বনাম প্রথাগত ব্যাকরণ)

## ৩. প্রতিটি টপিকের শর্টকাট: কীভাবে চিনবেন

- **কারক চেনার প্রশ্ন:** ক্রিয়াকে "কে/কারা" জিজ্ঞেস করলে উত্তর কর্তা, "কী/কাকে" জিজ্ঞেস করলে কর্ম। "কী দিয়ে/কীসের দ্বারা" করণ, "কাকে দান করা হলো (স্বত্ব ত্যাগ করে)" সম্প্রদান, "কোথা থেকে/কী থেকে (উৎস, ভয়, বিচ্যুতি)" অপাদান, আর "কোথায়/কখন/কোন বিষয়ে" অধিকরণ।
- **বিভক্তি দেখেই কারক ধরবেন না।** "তিলে" শব্দে -এ আছে, তবু এটি অপাদান, কারণ তেল তিল থেকে আসে। "ট্রেনে" শব্দে -এ আছে, তবু এটি করণ, কারণ ট্রেন যাতায়াতের উপায়।
- **সমাস:** উভয় পদের অর্থ প্রধান হলে দ্বন্দ্ব, পরপদের অর্থ প্রধান হলে কর্মধারয় বা তৎপুরুষ। ব্যাসবাক্যে বিভক্তি বা অনুসর্গ লোপ পেলে তৎপুরুষ, আর "যে/যিনি/যা" জুড়লে কর্মধারয়। তৃতীয় কোনো অর্থ বোঝালে বহুব্রীহি ("যার")। পূর্বপদ সংখ্যা আর অর্থ সমাহার হলে দ্বিগু, কিন্তু সংখ্যা থাকলেও "যার" এলে বহুব্রীহি। অব্যয় পূর্বপদ প্রধান হলে অব্যয়ীভাব।
- **"যার" থাকলেই বহুব্রীহি নয়।** "নীলকণ্ঠ" মানে নীল কণ্ঠ যার (শিব), তাই বহুব্রীহি। কিন্তু "নীল যে কণ্ঠ" ধরলে কর্মধারয়। প্রসঙ্গে ব্যক্তি বোঝালে বহুব্রীহি লিখুন।

### ৪.২ সন্ধি বিচ্ছেদ (৬০টি)

**স্বরসন্ধি:** বিদ্যালয় = বিদ্যা + আলয় · হিমালয় = হিম + আলয় · সিংহাসন = সিংহ + আসন · মহাশয় = মহা + আশয় · রবীন্দ্র = রবি + ইন্দ্র · গিরীশ = গিরি + ঈশ · সতীশ = সতী + ঈশ · অতীন্দ্রিয় = অতি + ইন্দ্রিয় · পরীক্ষা = পরি + ঈক্ষা · মরূদ্যান = মরু + উদ্যান · লঘূর্মি = লঘু + ঊর্মি · নরেশ = নর + ঈশ · মহেশ = মহা + ঈশ · যথেষ্ট = যথা + ইষ্ট · শুভেচ্ছা = শুভ + ইচ্ছা · সূর্যোদয় = সূর্য + উদয় · যথোচিত = যথা + উচিত · নীলোৎপল = নীল + উৎপল · মহর্ষি = মহা + ঋষি · রাজর্ষি = রাজা + ঋষি · জনৈক = জন + এক · মতৈক্য = মত + ঐক্য · সদৈব = সদা + এব · বনৌষধি = বন + ওষধি · মহৌষধ = মহা + ঔষধ · অত্যন্ত = অতি + অন্ত · অত্যধিক = অতি + অধিক · ইত্যাদি = ইতি + আদি · প্রত্যেক = প্রতি + এক · স্বল্প = সু + অল্প · স্বাগত = সু + আগত · অন্বেষণ = অনু + এষণ · নয়ন = নে + অন · শয়ন = শে + অন · পবন = পো + অন · গায়ক = গৈ + অক · নায়ক = নৈ + অক · পাবক = পৌ + অক · নাবিক = নৌ + ইক · গবাদি = গো + আদি

**নিপাতনে সিদ্ধ স্বরসন্ধি:** কুলটা = কুল + অটা · গবাক্ষ = গো + অক্ষ · প্রৌঢ় = প্র + ঊঢ় · অক্ষৌহিণী = অক্ষ + ঊহিনী · শুদ্ধোদন = শুদ্ধ + ওদন · মার্তণ্ড = মার্ত + অণ্ড

**ব্যঞ্জনসন্ধি:** দিগন্ত = দিক্ + অন্ত · বাগীশ = বাক্ + ঈশ · ষড়ানন = ষট্ + আনন · জগদীশ = জগৎ + ঈশ · সদুপায় = সৎ + উপায় · চলচ্চিত্র = চলৎ + চিত্র · উচ্চারণ = উৎ + চারণ · উজ্জ্বল = উৎ + জ্বল · সজ্জন = সৎ + জন · বিপজ্জনক = বিপদ্ + জনক · উল্লাস = উৎ + লাস · উল্লেখ = উৎ + লেখ · **উদ্ধার = উৎ + হার** · উদ্ধত = উৎ + হত · তদ্ধিত = তৎ + হিত · বাঙ্ময় = বাক্ + ময় · তন্ময় = তৎ + ময় · জগন্নাথ = জগৎ + নাথ · সঞ্চয় = সম্ + চয় · সন্তাপ = সম্ + তাপ · সম্মান = সম্ + মান · সংসার = সম্ + সার · সংবাদ = সম্ + বাদ · সংগীত = সম্ + গীত · অহংকার = অহম্ + কার · পরিচ্ছেদ = পরি + ছেদ · আচ্ছাদন = আ + ছাদন · কথাচ্ছলে = কথা + ছলে

**নিপাতনে সিদ্ধ ব্যঞ্জনসন্ধি:** বৃহস্পতি = বৃহৎ + পতি · বনস্পতি = বন + পতি · তস্কর = তৎ + কর · পতঞ্জলি = পতৎ + অঞ্জলি · গোষ্পদ = গো + পদ · একাদশ = এক + দশ · ষোড়শ = ষট্ + দশ · আশ্চর্য = আ + চর্য · পরস্পর = পর + পর

**বিসর্গসন্ধি:** মনোযোগ = মনঃ + যোগ · মনোরম = মনঃ + রম · তপোবন = তপঃ + বন · যশোদা = যশঃ + দা · তিরোধান = তিরঃ + ধান · শিরোনাম = শিরঃ + নাম · অধোগতি = অধঃ + গতি · নিরাকার = নিঃ + আকার · নিরাশা = নিঃ + আশা · দুরবস্থা = দুঃ + অবস্থা · পুনর্মিলন = পুনঃ + মিলন · আশীর্বাদ = আশীঃ + বাদ · নির্ধন = নিঃ + ধন · দুর্নীতি = দুঃ + নীতি · দুর্গম = দুঃ + গম · নিশ্চয় = নিঃ + চয় · দুশ্চিন্তা = দুঃ + চিন্তা · দুষ্কর = দুঃ + কর · নিষ্ফল = নিঃ + ফল · পুরস্কার = পুরঃ + কার · তিরস্কার = তিরঃ + কার · নমস্কার = নমঃ + কার · ভাস্কর = ভাঃ + কর · ইতস্তত = ইতঃ + তত · মনঃকষ্ট = মনঃ + কষ্ট · অন্তঃকরণ = অন্তঃ + করণ · প্রাতঃকাল = প্রাতঃ + কাল · নীরব = নিঃ + রব · নীরস = নিঃ + রস · নীরোগ = নিঃ + রোগ

### ৪.৪ বাগধারা: NCTB ২০২৬ বইয়ের পূর্ণ তালিকা (পরিচ্ছেদ ৪০) + পরীক্ষায় আসা অতিরিক্ত

> **উৎস:** NCTB বই, পৃষ্ঠা ১০৯–১১৩। বইয়ের প্রতিটি বাগধারা হুবহু, বইয়ের দেওয়া অর্থসহ। পরীক্ষায় অর্থ লেখার পর **নিজের একটি বাক্য** দেবেন।

**অ–ঈ:** অক্কা পাওয়া — মারা যাওয়া · অক্ষরে অক্ষরে — যথাযথ · অদৃষ্টের পরিহাস — ভাগ্যের খেলা · অনধিকার চর্চা — অপরের বিষয়ে হস্তক্ষেপ · অন্ধকার দেখা — দিশেহারা হয়ে পড়া · অন্ধের যষ্টি — একমাত্র অবলম্বন · অমাবস্যার চাঁদ — দুর্লভ বস্তু · অরণ্যে রোদন — নিষ্ফল অনুনয় · অর্ধচন্দ্র — ঘাড় ধাক্কা দেওয়া · আঁতে ঘা — খুব কষ্ট · আকাশ কুসুম — অসম্ভব কল্পনা · আগুন নিয়ে খেলা — বিপজ্জনক ঘটনার আশঙ্কা তৈরি করা · আঙুল ফুলে কলাগাছ — হঠাৎ বড়োলোক হওয়া · আঠারো মাসে বছর — দীর্ঘসূত্রিতা · আদা-জল খেয়ে লাগা — প্রাণপণ চেষ্টা করা · আমড়া কাঠের ঢেঁকি — অপদার্থ · আষাঢ়ে গল্প — আজগুবি গল্প · ইঁচড়ে পাকা — অকালপক্ব · ইতর বিশেষ — পার্থক্য

**উ–ক:** উড়নচণ্ডী — বেহিসেবি · উড়ে এসে জুড়ে বসা — অপ্রত্যাশিতভাবে জায়গা দখল করা · উড়োকথা — গুজব · উড়োচিঠি — বেনামি চিঠি · উত্তম-মধ্যম — বেদম প্রহার · উনিশ-বিশ — সামান্য পার্থক্য · এককথার মানুষ — দৃঢ়সংকল্প ব্যক্তি · এক ঢিলে দুই পাখি — এক প্রচেষ্টায় দুই ফল · এলাহি কাণ্ড — বিরাট আয়োজন · এসপার ওসপার — চূড়ান্ত মীমাংসা · ওজন বুঝে চলা — আত্মসম্মান রক্ষা করা · কচুকাটা করা — ধ্বংস করা · কড়ায় গণ্ডায় — চুলচেরা হিসাব · কথার কথা — গুরুত্বহীন কথা · কপাল ফেরা — সৌভাগ্য লাভ · কলমের এক খোঁচা — লিখিত আদেশ · কলুর বলদ — একটানা খাটুনি · কাঁচা পয়সা — নগদ উপার্জন · কাগজে কলমে — লিখিতভাবে · কাছাঢিলা — অসাবধান · কাঠখোট্টা — নীরস ও অনমনীয় · কানকাটা — নির্লজ্জ · কান খাড়া করা — ওত পেতে থাকা · কান ভাঙানো — কুপরামর্শ দেওয়া · কিস্তিমাত করা — সফলতা লাভ · কুয়োর ব্যাঙ — সংকীর্ণমনা লোক · কৈ মাছের প্রাণ — যা সহজে মরে না · কোমর বাঁধা — দৃঢ় সংকল্প · খয়ের খাঁ — চাটুকার · খেজুরে আলাপ — অকাজের কথা

**গ–ঠ:** গড্ডলিকা প্রবাহ — অন্ধ অনুকরণ · গভীর জলের মাছ — খুব চালাক · গরম গরম — তৎক্ষণাৎ · গা ঢাকা দেওয়া — পলায়ন করা · গায়ে পড়া — অযাচিত · গায়ে ফুঁ দিয়ে বেড়ানো — ফাঁকির মনোভাব · গুড়ে বালি — আশায় নৈরাশ্য · গোঁফ খেজুরে — খুব অলস · গোড়ায় গলদ — শুরুতেই ভুল · গোল্লায় যাওয়া — নষ্ট হওয়া · ঘোড়া ডিঙিয়ে ঘাস খাওয়া — মধ্যবর্তীকে অতিক্রম করে কাজ করা · ঘোড়ার ডিম — কিছুই না · চশমখোর — বেহায়া · চিনির বলদের মতো ঘানি টানা — ফল লাভে অংশীদার না হওয়া · চিনে জোঁক — নাছোড়বান্দা · চুনোপুঁটি — সামান্য ব্যক্তি · চুলোয় যাওয়া — নষ্ট হওয়া · চোখ পাকানো — রাগ দেখানো · চোখ বুঁজে থাকা — ভূমিকা না রাখা · চোখে সরষে ফুল দেখা — বিপদে দিশেহারা হওয়া · ছা-পোষা — অত্যন্ত গরিব · ছেলের হাতের মোয়া — সহজলভ্য · জগাখিচুড়ি — বিশৃঙ্খল · জিলাপির প্যাঁচ — কূটবুদ্ধি · ঝোপ বুঝে কোপ মারা — অবস্থা বুঝে সুযোগ গ্রহণ · টইটম্বুর — ভরপুর · টনক নড়া — সজাগ হওয়া · টাকার গরম — বিত্তের অহংকার · ঠোঁট কাটা — বেহায়া

**ড–ম:** ডান হাতের ব্যাপার — খাওয়া · ডুব মারা — পালিয়ে যাওয়া · ডুমুরের ফুল — অদৃশ্য বস্তু · তালকানা — কাণ্ডজ্ঞানহীন · তালপাতার সেপাই — ছিপছিপে · তাসের ঘর — স্বল্পস্থায়ী · তিলকে তাল করা — ছোটোকে বড়ো করা · তীর্থের কাক — সুযোগসন্ধানী · তেল মাখানো — তোষামোদ · থতমত খাওয়া — অপ্রস্তুত হয়ে পড়া · দা-কুমড়া সম্পর্ক — শত্রুতা · দিবাস্বপ্ন — অলীক কল্পনা · দুধের মাছি — সুসময়ের বন্ধু · ধরাকে সরা জ্ঞান — অহংকার করা · ননীর পুতুল — শ্রমবিমুখ · নয়-ছয় — অপব্যবহার · পটল তোলা — মারা যাওয়া · পুঁটি মাছের প্রাণ — ছোটো মন · বইয়ের পোকা — সব সময় বই পড়ে এমন · বর্ণচোরা — ভণ্ড · বাঘের দুধ — অসম্ভব বস্তু · বিনা মেঘে বজ্রপাত — অপ্রত্যাশিত বিপদ · বুদ্ধির ঢেঁকি — নির্বোধ · ভরাডুবি — সর্বনাশ · ভিজে বিড়াল — কপট ব্যক্তি · ভিটায় ঘুঘু চরানো — নিঃস্ব করা · ভুঁইফোঁড় — নতুন আগমন · মগের মুল্লুক — অরাজকতা · মণিকাঞ্চন যোগ — উপযুক্ত মিলন · মানিক জোড় — গভীর সম্পর্ক

**ল–হ:** লেফাফা দুরস্ত — বাইরে পরিপাটি · সপ্তমে চড়া — প্রচণ্ড উত্তেজনা · সোনায় সোহাগা — উপযুক্ত মিলন · হাতটান — চুরির অভ্যাস · হাতেখড়ি — শিক্ষার শুরু

**NCTB-র বাইরে, কিন্তু ব্যাংক বা BCS-এ এসেছে:** **অগস্ত্য যাত্রা — চিরদিনের জন্য প্রস্থান (জুন ২০২৬)** · অকালকুষ্মাণ্ড — অপদার্থ · অগ্নিমূল্য — দুর্মূল্য · অষ্টরম্ভা — ফাঁকি · আকাশ ভেঙে পড়া — হঠাৎ বিপদ · আদায় কাঁচকলায় — তীব্র শত্রুতা · উভয় সংকট / শাঁখের করাত — দুই দিকেই বিপদ · উলুবনে মুক্তা ছড়ানো — অপাত্রে মূল্যবান বস্তু দান · একাদশে বৃহস্পতি — সৌভাগ্যের বিষয় · কাঁঠালের আমসত্ত্ব — অসম্ভব বস্তু · কাকতালীয় — দৈবক্রমে মিলে যাওয়া · কূপমণ্ডূক — সংকীর্ণমনা · কেঁচো খুঁড়তে সাপ — সামান্য খুঁজতে গিয়ে বড় বিপদ · গোবর গণেশ — মূর্খ · গোকুলের ষাঁড় / ধর্মের ষাঁড় — স্বেচ্ছাচারী · গৌরচন্দ্রিকা — ভূমিকা · ঘোড়ারোগ — সাধ্যের বাইরে শখ · ঘাটের মড়া — অতি বৃদ্ধ · চোখের বালি — চক্ষুশূল · ঢাকের কাঠি — মোসাহেব · ঢাকের দায়ে মনসা বিকানো — সামান্য প্রয়োজনে বেশি খরচ · তামার বিষ — অর্থের কুপ্রভাব · তুলসী বনের বাঘ / বকধার্মিক / বিড়াল তপস্বী — ভণ্ড · ধরি মাছ না ছুঁই পানি — দায় না নিয়ে কৌশলে কাজ সারা · নুন আনতে পান্তা ফুরায় — চরম অভাব · পুকুরচুরি — বড় রকমের চুরি · ভূতের বাপের শ্রাদ্ধ — অপব্যয় · মাছের মায়ের পুত্রশোক — কপট দুঃখ · রাঘব বোয়াল — ক্ষমতাশালী বড় অপরাধী · রাবণের চিতা — চির অশান্তি · শিকায় তোলা — স্থগিত রাখা · শিরে সংক্রান্তি — আসন্ন বিপদ · সাক্ষী গোপাল — নিষ্ক্রিয় দর্শক · সাপের পাঁচ পা দেখা — অহংকারে স্পর্ধিত হওয়া · হরিহর আত্মা — গভীর বন্ধুত্ব · হাটে হাঁড়ি ভাঙা — গোপন কথা ফাঁস করা · হাড়ে দূর্বা গজানো — অতিশয় অলস · দহরম-মহরম — ঘনিষ্ঠতা · শকুনি মামা — কুচক্রী

### ৪.৫ প্রবাদ-প্রবচনের নিহিতার্থ (২৫টি)

খাতায় "আক্ষরিক অর্থ" নয়, **শিক্ষা বা ভাবার্থটি** লিখবেন।

|---|---|
| অতি লোভে তাঁতি নষ্ট | মাত্রাতিরিক্ত লোভে নিজেরই ক্ষতি হয় |
| দশের লাঠি একের বোঝা | সবাই মিলে করলে কঠিন কাজও সহজ |

| দুষ্ট গরুর চেয়ে শূন্য গোয়াল ভালো | খারাপ সঙ্গীর চেয়ে সঙ্গী না থাকাই ভালো |

| বজ্র আঁটুনি ফস্কা গেরো | বাইরে কড়াকড়ি, ভেতরে ফাঁক (ব্যাংকিং সুশাসনের উদাহরণে চমৎকার) |

### ৪.৬ এক কথায় প্রকাশ (৮০টি)

**"অ-/দুঃ-" জোড়া (সবচেয়ে বেশি আসে):** যা পূর্বে দেখা যায়নি — অদৃষ্টপূর্ব · যা পূর্বে হয়নি — অভূতপূর্ব · যা পূর্বে শোনা যায়নি — অশ্রুতপূর্ব · যা পূর্বে চিন্তা করা যায়নি — অচিন্তিতপূর্ব · যা পূর্বে ছিল — ভূতপূর্ব · যা বলা হয়নি — অনুক্ত · যা বলার যোগ্য নয় — অকথ্য · যা বর্ণনা করা যায় না — অবর্ণনীয় · যা অতিক্রম করা যায় না — অনতিক্রম্য · যা সহজে অতিক্রম করা যায় না — দুরতিক্রম্য · যা সহজে লাভ করা যায় না — দুর্লভ · যা জয় করা যায় না — অজেয় · যা কষ্টে জয় করা যায় — দুর্জয় · যা জানা যায় না — অজ্ঞেয় · যা সহজে জানা যায় না — দুর্জ্ঞেয় · যা নিবারণ করা যায় না — অনিবার্য · যা কষ্টে নিবারণ করা যায় — দুর্নিবার · যা দমন করা কষ্টকর — দুর্দমনীয় · যা দূর করা কষ্টকর — দুরপনেয় · যা ক্ষমার অযোগ্য — অমার্জনীয় · যা চিরস্থায়ী নয় — নশ্বর / অনিত্য · যার বিনাশ নেই — অবিনশ্বর · যা পরিমাপ করা যায় না — অপরিমেয়

**মানুষ:** বক্তৃতায় পটু — বাগ্মী · বেশি কথা বলে — বাচাল · কম কথা বলে — মিতভাষী · যিনি ব্যাকরণ জানেন — বৈয়াকরণ · যার উপস্থিত বুদ্ধি আছে — প্রত্যুৎপন্নমতি · ভবিষ্যৎ না ভেবে কাজ করে — অবিমৃশ্যকারী · একবার শুনেই মনে রাখতে পারে — শ্রুতিধর · একই গুরুর শিষ্য — সতীর্থ · যার শত্রু জন্মায়নি — অজাতশত্রু · যার কিছুতেই ভয় নেই — অকুতোভয় · দুই হাত সমান চলে — সব্যসাচী · যার মন অন্যদিকে — অন্যমনস্ক · অহংকার নেই যার — নিরহংকার · বংশ ও স্বভাব জানা নেই — অজ্ঞাতকুলশীল · উপকারীর উপকার স্বীকার করে — কৃতজ্ঞ · উপকার স্বীকার করে না — অকৃতজ্ঞ · উপকারীর অপকার করে — কৃতঘ্ন · বিদেশে থাকে — প্রবাসী · মৃত্যুর পথযাত্রী — মুমূর্ষু · **যে ঋণ নেয় — অধমর্ণ** · **যে ঋণ দেয় — উত্তমর্ণ** · যার স্ত্রী মারা গেছে — বিপত্নীক · যে বিয়ে করেনি (পুরুষ) — অকৃতদার · যে নারী নিজে স্বামী বেছে নেয় — স্বয়ংবরা · যে নারী বীর সন্তানের জননী — বীরপ্রসূ · যে নারী সূর্য দেখেনি — অসূর্যম্পশ্যা · যার সন্তান বাঁচে না — মৃতবৎসা · যার স্বামী প্রবাসে — প্রোষিতভর্তৃকা

**ইচ্ছা (-ইষা/-সা):** জানার ইচ্ছা — জিজ্ঞাসা · জয়ের ইচ্ছা — জিগীষা · বাঁচার ইচ্ছা — জিজীবিষা · হত্যার ইচ্ছা — জিঘাংসা · মুক্তির ইচ্ছা — মুমুক্ষা · লাভের ইচ্ছা — লিপ্সা · খাওয়ার ইচ্ছা — বুভুক্ষা · পান করার ইচ্ছা — পিপাসা · কিছু করার ইচ্ছা — চিকীর্ষা · মৃত্যুর ইচ্ছা — মুমূর্ষা

**প্রাণী, প্রকৃতি ও খাদ্য:** জলে ও স্থলে চরে — উভচর · আকাশে চরে — খেচর · রাতে চরে — নিশাচর · হাতির ডাক — বৃংহিত · ঘোড়ার ডাক — হ্রেষা · ময়ূরের ডাক — কেকা · পাখির ডাক — কূজন · ভ্রমরের ডাক — গুঞ্জন · ফল পাকলে যে গাছ মরে যায় — ওষধি · যে গাছ কাজে লাগে না — আগাছা · দিন ও রাতের সন্ধিক্ষণ — গোধূলি · ঈষৎ উষ্ণ — কবোষ্ণ · উঁচু-নিচু — বন্ধুর · পা থেকে মাথা পর্যন্ত — আপাদমস্তক · মাটি দিয়ে তৈরি — মৃন্ময় · জ্ঞানময় — চিন্ময় · ক্রমশ বাড়ছে — বর্ধিষ্ণু · চিবিয়ে খেতে হয় — চর্ব্য · চুষে খেতে হয় — চোষ্য · চেটে খেতে হয় — লেহ্য · পান করতে হয় — পেয়

### ৪.৭ বানান: নিয়ম ও শুদ্ধ তালিকা

**বাংলা একাডেমির প্রমিত বানানের ৮টি নিয়ম, শুদ্ধ উদাহরণসহ** (প্রশ্ন আসতে পারে: "প্রমিত বানানের পাঁচটি নিয়ম লিখুন")

1. **তৎসম শব্দে ই/ঈ বা উ/ঊ দুটোই শুদ্ধ হলে হ্রস্ব রূপ লেখা হবে:** শ্রেণি, পদবি, ধমনি, পল্লি, ভঙ্গি, সূচিপত্র। *(শ্রেণি তৎসম শব্দ, অতৎসম নয়। ই-কার এসেছে এই নিয়মে।)*
2. **রেফের পর ব্যঞ্জনের দ্বিত্ব হবে না:** কার্য (কার্য্য নয়), সূর্য (সূর্য্য নয়), অর্চনা (অর্চ্চনা নয়), অর্জন (অর্জ্জন নয়), ধর্ম (ধর্ম্ম নয়), কর্ম (কর্ম্ম নয়)।
3. **সন্ধিতে ক-বর্গ পরে থাকলে পূর্বপদের ম্ হয় ং:** অহংকার, সংগীত, শুভংকর, সংখ্যা, সংঘ। (অহঙ্কার/সঙ্গীতও চলে, তবে প্রমিত রূপ ং।)
4. **অতৎসম (তদ্ভব, দেশি, বিদেশি, মিশ্র) শব্দে শুধু ই-কার:** সরকারি, দরকারি, চাকরি, তৈরি, বাড়ি, গাড়ি, কোম্পানি, ডিগ্রি। জাতি ও ভাষার নামেও: ইংরেজি, জাপানি, বাঙালি, আরবি। অতৎসম স্ত্রীবাচক শব্দে: নানি, দাদি, মামি, রানি, বাঘিনি। -আলি প্রত্যয়ে: সোনালি, রুপালি, মিতালি, বর্ণালি। *(তৎসম স্ত্রীবাচকে ঈ থাকে: ছাত্রী, তরুণী, রাজ্ঞী, বিদুষী।)*
5. **অতৎসম শব্দে ণ ও ষ নয়:** কান, সোনা, ঝরনা, গভর্নর, কোরআন, পোস্ট, স্টেশন, মাস্টার। তদ্ভব শব্দে "ক্ষ"-এর বদলে "খ": খেত, খুদ, খিদে।
6. **'কী' ও 'কি':** প্রশ্নের উত্তর যদি হ্যাঁ বা না না হয়ে কোনো তথ্য হয়, তবে **কী** ("তুমি কী খাবে?")। হ্যাঁ/না উত্তরের প্রশ্নে অব্যয় **কি** ("তুমি কি যাবে?")।
7. **না-বাচক 'না' আলাদা, 'নি' জুড়ে লেখা:** করে না, যাব না; কিন্তু করেনি, যায়নি।
8. **বিসর্গ বর্জন (পদের শেষে):** কার্যত, মূলত, প্রধানত, ভুলবশত (কার্যতঃ নয়)। তবে সন্ধিজাত শব্দে বিসর্গ থাকে: ইতঃপূর্বে, অন্তঃকরণ, দুঃখ।

**ণত্ব বিধান (তৎসম শব্দে):** ঋ, র, ষ-এর পরে ন হয় ণ: ঋণ, বর্ণ, ভাষণ। মাঝে স্বরবর্ণ, ক-বর্গ, প-বর্গ, য, য়, হ, ং থাকলেও তা-ই হয়: কৃপণ, গ্রহণ, অর্পণ। ট-বর্গের সঙ্গে যুক্ত হলে ণ হয়: ঘণ্টা, কাণ্ড, লুণ্ঠন। কিন্তু ত-বর্গের সঙ্গে সবসময় ন: গ্রন্থ, বৃন্ত। **ফাঁদ:** পূর্বাহ্ণ ও অপরাহ্ণ-তে ণ, কিন্তু মধ্যাহ্ন-তে ন।
**ষত্ব বিধান:** অ ও আ ছাড়া অন্য স্বর এবং ক ও র-এর পরে প্রত্যয়ের স হয় ষ: ভবিষ্যৎ, মুমূর্ষু। ই বা উ-কারান্ত উপসর্গের পরে কিছু ধাতুতে ষ হয়: অভিষেক, সুষম, অনুষ্ঠান। ট ও ঠ-এর সঙ্গে যুক্ত হলে ষ: কষ্ট, নিষ্ঠা, কাষ্ঠ। বিদেশি শব্দে ষ হয় না: পোস্ট, মাস্টার।

### ৪.১০ বাচ্য (সিলেবাসের বাইরে, কিন্তু ব্লুপ্রিন্টে এসেছে)

| বাচ্য | চেনার উপায় | উদাহরণ |
|---|---|---|
| **কর্তৃবাচ্য** | কর্তা প্রধান, ক্রিয়া কর্তার অনুসারী | আমি ভাত খাই। শিকারি বাঘ মেরেছে। |
| **কর্মবাচ্য** | কর্ম প্রধান; কর্তার পরে "দ্বারা/কর্তৃক/দিয়ে" বসে বা কর্তা উহ্য থাকে | রবীন্দ্রনাথ **কর্তৃক** গীতাঞ্জলি রচিত হয়েছে। চোর ধরা পড়েছে। আসামিকে জরিমানা করা হয়েছে। |
| **ভাববাচ্য** | ক্রিয়ার ভাব প্রধান; কর্তা ষষ্ঠী বা "দ্বারা/দিয়ে"-যুক্ত হয়, কর্ম থাকে না; ক্রিয়া সাধারণত "হওয়া/যাওয়া" | **আমার** যাওয়া **হবে না**। এবার **ওঠা যাক**। তোমাকে দিয়ে… আশা **করা যায় না**। |
| **কর্মকর্তৃবাচ্য** (প্রথাগত) | কর্ম নিজেই কর্তার মতো আচরণ করে | বাঁশি **বাজে**। কলমটা লেখে ভালো। ঘণ্টা বাজে। |

**রূপান্তর:** কর্তৃ থেকে কর্ম: শিকারি বাঘ মেরেছে → শিকারি **কর্তৃক** বাঘ **নিহত হয়েছে**। কর্তৃ থেকে ভাব: আমি যাব না → **আমার যাওয়া হবে না**; তুমি কখন যাবে → **তোমার কখন যাওয়া হবে**; সে খেতে পারে না → **তার খাওয়া হয় না**। কর্ম থেকে কর্তৃ: চোর ধরা পড়েছে → (পুলিশ) চোর ধরেছে।

**NCTB ২০২৬ বইয়ের উদাহরণ (হুবহু, বানান বইয়ের মতো):** NCTB ৩ ধরনের বাচ্য মানে: **কর্তাবাচ্য**, **কর্মবাচ্য**, **ভাববাচ্য**। প্রথাগত বইয়ে চতুর্থটি **কর্মকর্তৃবাচ্য**। পরীক্ষায় লিখবেন "প্রথাগত মতে কর্মকর্তৃবাচ্য; NCTB মতে কর্তাবাচ্য"।

- কর্তাবাচ্য: ঝরনা ছবি আঁকে। ফ্যানটা অনেক জোরে ঘুরছে।
- কর্মবাচ্য: পুলিশ কর্তৃক ডাকাত ধৃত হয়েছে। চিঠিটা পড়া হয়েছে।
- ভাববাচ্য: আমার যাওয়া হলো না। কোথা থেকে আসা হলো?
- রূপান্তর (NCTB): জাহানারা ইমাম একাত্তরের দিনগুলি রচনা করেছেন → জাহানারা ইমাম **কর্তৃক** একাত্তরের দিনগুলি **রচিত হয়েছে** · তুমি কখন এলে → **কখন আসা হলো** · একটু বাইরে বেড়িয়ে **আসা যাক** → একটু বাইরে বেড়িয়ে **আসি** (ভাব থেকে কর্তা) · আমাদের কঠোর পরিশ্রম **করতে হয়** → **আমরা** কঠোর পরিশ্রম **করি**।

**২ নম্বরের উত্তরের ছাঁচ:** "বাক্যটি কর্তৃবাচ্যের। কর্মবাচ্যে রূপ: ___। কারণ: কর্মবাচ্যে কর্মপদ প্রধান হয়, কর্তার পরে 'কর্তৃক/দ্বারা' বসে এবং ক্রিয়া কর্মের অনুসারী হয়।"

## ৫. তিনটি মক প্রশ্নপত্র (জুন ২০২৬-এর ধরনে)

**নিয়ম:** খাতায় হাতে লিখুন, প্রতিটি পেপারে ৮ মিনিট। এরপর উত্তরমালা মিলিয়ে নম্বর দিন। §২-এর ফর্মুলা না মানলে প্রতিটি ভুলে ১ নম্বর কেটে নিজেকে নম্বর দিন।

### মক ১
(ক) "রাঘব বোয়াল" বাগধারার অর্থ লিখে বাক্যে প্রয়োগ করুন। (খ) "আমার আজ যাওয়া হবে না" — কোন বাচ্য? (গ) "সম্রাট"-এর স্ত্রীবাচক শব্দ লিখুন। (ঘ) "ভিক্ষুককে ভিক্ষা দাও" — দাগানো পদের কারক ও বিভক্তি নির্ণয় করুন। (ঙ) "বীণাপাণি"-র ব্যাসবাক্য লিখে সমাসের নাম লিখুন।

### মক ২
(ক) "বজ্র আঁটুনি ফস্কা গেরো" প্রবাদের নিহিতার্থ লিখুন। (খ) সন্ধিবিচ্ছেদ করুন: আশীর্বাদ, উচ্চারণ। (গ) শুদ্ধ করুন: "দেশের সকল নাগরিকগণ ভোট দেবেন।" (ঘ) এক কথায় প্রকাশ করুন: "যে ঋণ দেয়"; "যা পূর্বে কখনো হয়নি"। (ঙ) "লক্ষ" ও "লক্ষ্য" শব্দের অর্থের পার্থক্য দেখিয়ে বাক্য রচনা করুন।

### মক ৩
(ক) শুদ্ধ বানান লিখুন: মুহুর্ত, প্রতিযোগীতা, স্বায়ত্বশাসন, মন্ত্রীসভা। (খ) "টাকায় টাকা আনে" — দাগানো পদের কারক ও বিভক্তি নির্ণয় করুন। (গ) "দম্পতি" ও "ত্রিফলা"-র ব্যাসবাক্য ও সমাস লিখুন। (ঘ) "সাক্ষর" ও "স্বাক্ষর"-এর পার্থক্য লিখুন। (ঙ) বাংলা একাডেমির প্রমিত বানানের যেকোনো দুটি নিয়ম উদাহরণসহ লিখুন।

### উত্তরমালা

**মক ১:** (ক) রাঘব বোয়াল = ক্ষমতাশালী বড় অপরাধী। *ঋণখেলাপি রাঘব বোয়ালদের বিচার না হলে ব্যাংক খাত সুস্থ হবে না।* (খ) **ভাববাচ্য**: ক্রিয়ার ভাব প্রধান, কর্তা "আমার" ষষ্ঠী বিভক্তিতে। (গ) **সম্রাজ্ঞী**। (ঘ) **সম্প্রদান কারকে ৪র্থী বিভক্তি** (স্বত্ব ত্যাগ করে দান; NCTB ২০২৬ মতে কর্ম কারক)। (ঙ) বীণা পাণিতে যার — **ব্যধিকরণ বহুব্রীহি**।
**মক ২:** (ক) বাইরে কড়াকড়ি, ভেতরে ফাঁক। নিয়মকানুন কাগজে কঠোর হলেও প্রয়োগে দুর্বলতা থাকে। (খ) আশীঃ + বাদ (বিসর্গসন্ধি); উৎ + চারণ (ব্যঞ্জনসন্ধি)। (গ) দেশের **সকল নাগরিক** ভোট দেবেন। (দ্বৈত বহুবচন) (ঘ) **উত্তমর্ণ**; **অভূতপূর্ব**। (ঙ) লক্ষ = শত হাজার: *প্রকল্পে দশ লক্ষ টাকা লাগবে।* লক্ষ্য = উদ্দেশ্য: *আমার লক্ষ্য ব্যাংকার হওয়া।*
**মক ৩:** (ক) মুহূর্ত, প্রতিযোগিতা, স্বায়ত্তশাসন, মন্ত্রিসভা। (খ) প্রথম "টাকায়" = **কর্তায় ৭মী বিভক্তি**। (গ) জায়া ও পতি — **দ্বন্দ্ব**; তিন ফলের সমাহার — **দ্বিগু** (NCTB মতে দ্বিগু কর্মধারয়)। (ঘ) সাক্ষর = অক্ষরজ্ঞানসম্পন্ন (*দেশে সাক্ষরতার হার বাড়ছে*); স্বাক্ষর = দস্তখত (*চেকে স্বাক্ষর মেলেনি*)। (ঙ) §৪.৭-এর নিয়ম ১–৮ থেকে যেকোনো দুটি, উদাহরণসহ।

# ০৯ · গ্রামার কুইক শিট (ইংরেজি ২০ + বাংলা ১০)

> প্রশ্নের ধরন এখনো নিশ্চিত নয় (নতুন অংশ)। সম্ভাব্য ধরন: ভুল শুদ্ধকরণ, right form of verbs, transformation, narration, preposition, বাংলা বানান/বাক্যশুদ্ধি, সমাস, সন্ধি, প্রবাদ। পুরো বই না পড়ে এই শিট আর NCTB বইয়ের অনুশীলনী দিয়ে চালিয়ে নিন।

## ইংরেজি: সবচেয়ে বেশি নম্বর আসে যে ১২টি নিয়মে

| # | নিয়ম | উদাহরণ (ভুল → শুদ্ধ) |
|---|---|---|
| ১ | **Subject-verb agreement:** Each/Every/Either/Neither/One of + plural noun → singular verb | One of the banks **are** → One of the banks **is** |
| ২ | A number of + plural verb; The number of + singular verb | The number of defaulters **are** → **is** rising |
| ৩ | News, economics, mathematics → singular | Economics **are** → **is** |
| ৪ | Since/For: since + সময়ের শুরু, for + সময়কাল; present perfect সাথে | I **am** here since 2020 → I **have been** here since 2020 |
| ৫ | If-clause: If + past, would + base; If + past perfect, would have + V3 | If he **would come**, I would go → If he **came**, ... |
| ৬ | It is time / It is high time + past | It is high time we **take** → **took** action |
| ৭ | Would that / I wish + past (বর্তমানের অবাস্তব ইচ্ছা) | I wish I **am** rich → **were** |
| ৮ | Lest + should | Read attentively lest you **fail** → **should fail** |
| ৯ | Prefer to / superior to / senior to / averse to (than নয়) | senior **than** me → senior **to** me |
| ১০ | Article: an honest, a university, an MBA, the + superlative/unique | **a** honest man → **an** honest man |
| ১১ | Passive: Modal + be + V3; Let + obj + be + V3 | The loan must **repaid** → must **be repaid** |
| ১২ | Narration: said to → told/asked/requested; tense এক ধাপ পিছিয়ে; now→then, today→that day, here→there | He said, "I am busy." → He said that he **was** busy. |

**Transformation:** Simple ↔ Complex ↔ Compound
- Simple: *Being ill, he could not attend.*
- Complex: *As he was ill, he could not attend.*
- Compound: *He was ill **and so** he could not attend.*
- Affirmative ↔ Negative: *Only he can do it → None but he can do it.* · *He is too weak to walk → He is so weak that he cannot walk.*
- Degree: *Dhaka is the largest city → No other city is as large as Dhaka / Dhaka is larger than any other city.*

**প্রায়ই আসা Preposition:** comply **with**, abide **by**, prior **to**, independent **of**, dependent **on**, consist **of**, insist **on**, refrain **from**, invest **in**, deal **with**, accused **of**, charged **with**, according **to**, in spite **of** (despite + no of)।

**বানান যা প্রায়ই ভুল হয়:** accommodation, commitment, occurrence, entrepreneur, government, environment, guarantee, liaison, millennium, necessary, privilege, recommend, separate, threshold, embarrass, colleague, receive, definitely, independent, maintenance।

## বাংলা: ১০ নম্বরের জন্য

**বানান (ণত্ব-ষত্ব ও ই-কার):**
- শুদ্ধ: সরকারি, দরকারি, তৈরি, জাতীয়, শ্রেণি, বাড়ি, গাড়ি, ইংরেজি, কোম্পানি, পদবি, প্রতিযোগিতা, মুহূর্ত, উজ্জ্বল, পরিস্থিতি, দুরবস্থা, সমীচীন, ভৌগোলিক, নিরীক্ষণ, ইতিমধ্যে, অধীন, সূচিপত্র, মরীচিকা, স্বায়ত্তশাসন, উচ্ছ্বাস, শ্মশান, পুরস্কার, ব্যবস্থা, দুর্নীতি, মূল্যস্ফীতি, ঊর্ধ্বগতি
- নিয়ম: বিদেশি, তদ্ভব আর দেশি শব্দে সাধারণত ই-কার বসে (সরকারি, চাকরি)। তৎসম শব্দে মূল বানান বজায় থাকে (শ্রেণী নয়, **শ্রেণি**; জাতি, নীতি)।

**বাক্যশুদ্ধি (ক্লাসিক):**
| অশুদ্ধ | শুদ্ধ |
|---|---|
| তিনি স্বস্ত্রীক এসেছেন | তিনি **সস্ত্রীক** এসেছেন |
| দারিদ্রতা | **দারিদ্র্য / দরিদ্রতা** |
| সকল ছাত্ররা | **সকল ছাত্র / ছাত্ররা** |
| আবশ্যকীয় | **আবশ্যক** |
| উৎকর্ষতা | **উৎকর্ষ** |
| সৌজন্যতা | **সৌজন্য** |
| অত্যাধিক | **অত্যধিক** |
| ইতিপূর্বে | **ইতঃপূর্বে** |
| পৈত্রিক | **পৈতৃক** |
| মহারাজা | **মহারাজ** |
| সাবধানপূর্বক | **সাবধানে** |
| বাহুল্যতা | **বাহুল্য** |

**সমাস (দ্রুত চেনা):** দ্বন্দ্ব (মা-বাবা), কর্মধারয় (নীলপদ্ম), তৎপুরুষ (রাজপুত্র = রাজার পুত্র), বহুব্রীহি (দশানন), দ্বিগু (ত্রিভুবন), অব্যয়ীভাব (প্রতিদিন)।

**সন্ধি:** বিদ্যা+আলয় = বিদ্যালয়; সম্+তাপ = সন্তাপ; উৎ+হার = উদ্ধার; নিঃ+রোগ = নীরোগ; পর+পর = পরস্পর; তৎ+হিত = তদ্ধিত।

**প্রবাদ/বাগধারা (রচনাতেও কাজে লাগে):** অগ্নিমূল্য (খুব দামি), গোঁফ খেজুরে (অলস), কাঁঠালের আমসত্ত্ব (অসম্ভব বস্তু), সাপের পাঁচ পা দেখা (অহংকারী হওয়া), শাঁখের করাত (উভয় সংকট), ঢাকের কাঠি (মোসাহেব), ভরাডুবি (সর্বনাশ)।

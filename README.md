পরীক্ষা: **শুক্রবার, ২৭ নভেম্বর ২০২৬, সকাল ৯:৩০–১১:৩০ · ২০০ নম্বর** · ৯০৩টি পদ · Job ID 26101 · কেন্দ্র ঢাকায় · MCQ-এর প্রবেশপত্র সঙ্গে নিন (erecruitment.bb.org.bd-তে মিলিয়ে নিন)

এই রিপোতে ৭২টি PDF (প্রায় ২,৮০০ পৃষ্ঠা) আছে। এগুলো পরীক্ষার অংশ অনুযায়ী সাজানো হয়েছে, OCR করে সার্চযোগ্য করা হয়েছে, আর এগুলোর ওপর একটি কমান্ড-লাইন **প্রস্তুতি ইঞ্জিন** বানানো হয়েছে।

## 🚀 ৩০ সেকেন্ডে শুরু

```bash
python3 engine/so.py
```
এতে আজকের কাজ আর কত দিন বাকি, দুটোই দেখাবে। এরপর:

```bash
python3 engine/so.py topic 1          # টপিক কার্ড: কাঠামো, সর্বশেষ সংখ্যা, সমাধান, উৎস PDF
python3 engine/so.py essay --timer    # র‍্যান্ডম রচনা + ১৮ মিনিটের টাইমার
python3 engine/so.py arg --timer      # আর্গুমেন্ট প্রম্পট + ২২ মিনিট
python3 engine/so.py math work -n 5   # বিগত প্রশ্ন থেকে ৫টি অঙ্ক
python3 engine/so.py tr               # বাংলা→ইংরেজি অনুবাদ ড্রিল
python3 engine/so.py terms --quiz 15  # ব্যাংকিং পরিভাষার ফ্ল্যাশকার্ড
python3 engine/so.py facts            # রচনায় বসানোর সর্বশেষ সংখ্যা
python3 engine/so.py search "খেলাপি ঋণ"   # ২,৮০০ পৃষ্ঠার মধ্যে সার্চ (পৃষ্ঠা নম্বরসহ)
python3 engine/so.py mock             # নতুন কাঠামোর ২০০ নম্বরের মক প্রশ্নপত্র
python3 engine/so.py stats            # অগ্রগতি
```
শুধু Python 3 লাগবে, বাইরের কোনো প্যাকেজ নয়। ফোনে চালাতে চাইলে Termux, Pydroid বা অনলাইন Python ব্যবহার করতে পারেন। আর সব তথ্য `docs/`-এর Markdown ফাইলেও আছে।

### 🧑‍🏫 AI পরীক্ষক ("AI খাতা দেখা" ট্যাব)
খাতায় লিখে ছবি দিন, পরীক্ষকের মতো নম্বর পান:
1. **প্রশ্ন নিন:** আজকের ফোকাস (GK, ব্যাংকিং, বাংলা ব্যাকরণ, অনুবাদ, বাংলা ফোকাস রাইটিং), যেকোনো অংশ, মক প্রশ্নপত্র, অথবা নিজের প্রশ্ন।
2. **খাতায় লিখুন:** টাইমার ঐচ্ছিক।
3. **ছবি দিন:** ঘোরানো আর ক্রম বদলানো যায়। ছবি স্বয়ংক্রিয়ভাবে পরিষ্কার হয়, আর লম্বা পৃষ্ঠা দুই ভাগে পড়া হয় যাতে ছোট লেখাও পড়া যায়।
4. **AI হুবহু পড়ে:** আপনার ভুলসহ পড়ে, আর হাতের লেখা কতটা পড়া যায় তার মান দেয়। আপনি শুধু পড়ার ভুল ঠিক করবেন।
5. **দুই ধাপে নম্বর:** পরীক্ষক ১ রুব্রিক ধরে প্রমাণসহ নম্বর দেন, তারপর প্রধান পরীক্ষক প্রতিটি নম্বর আবার যাচাই করেন।
6. **কোডের যাচাই:** কোড প্রতিটি নম্বর সীমার মধ্যে রাখে আর নিজে যোগফল করে। উদ্ধৃত প্রমাণ আপনার লেখায় না থাকলে সেই নম্বর অর্ধেক করে দেয়। লেখা খুব ছোট হলে মোট নম্বরে সীমা বসায়।
7. **ফলাফলে যা পাবেন:** মানদণ্ড বা প্রশ্নভিত্তিক নম্বর, খাতার লেখায় ভুল চিহ্নিত, ২০ নভেম্বরের যাচাই করা তথ্যের সাথে মিলিয়ে তথ্য-যাচাই, পরের বারের ৩টি করণীয় আর আদর্শ রূপ।
8. **মনিটরিং:** অংশভিত্তিক ধারা, বারবার হওয়া ভুল আর AI কোচের ২৪ ঘণ্টার পরিকল্পনা। নম্বর মূল্যায়ন ট্যাবের প্রজেকশনেও যোগ হয়।

**ইঞ্জিন:**
- **claude.ai-তে:** Claude নিজেই মূল্যায়ক, কোনো key লাগে না।
- **নিজের API (যেমন AgentRouter):** "AI সেটিংস"-এ দিন। key শুধু সেই ব্রাউজারে থাকে, git বা ব্যাকআপে যায় না। এটা শুধু ডাউনলোড করা `index.html`-এ চলে, কারণ claude.ai-র ভেতরে বাইরের সংযোগ বন্ধ।

যা আছে: ৫× দৈনিক কোটা (দিনে ৫ রচনা, ৫ আর্গুমেন্ট, ৫ অনুবাদ, ৪৫ অঙ্ক, ৭৫ পরিভাষা), দিনভিত্তিক সময়সূচি, টাইমার (রিলোডেও চলে), রুব্রিক দিয়ে স্ব-মূল্যায়ন, ১,২৩৬টি বিগত গণিত প্রশ্নের ড্রিল ও ভুলের খাতা, পরিভাষার ফ্ল্যাশকার্ড, ইংরেজি/বাংলা/তথ্য MCQ, পূর্ণ ও লেখার মক টেস্ট, অংশভিত্তিক প্রজেক্টেড নম্বর, দুর্বল জায়গা আর ব্যাকআপ।


## 🔧 রক্ষণাবেক্ষণ

```bash
# নতুন PDF যোগ করলে: engine/catalog.py-তে একটি লাইন যোগ করুন, তারপর
python3 engine/extract.py --only <নামের অংশ>
python3 engine/build_math_bank.py
python3 engine/mine_past_questions.py
python3 engine/build_docs.py
```
OCR-এর জন্য লাগবে: `poppler-utils`, `tesseract-ocr`, `tesseract-ocr-ben`।

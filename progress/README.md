# অগ্রগতি লগ

`python3 engine/so.py log <অংশ> <সংখ্যা> "নোট"` দিয়ে যোগ হয় (`log.csv`), আর `python3 engine/so.py stats` দিয়ে দেখা যায়।
অংশ কোড: FW_BN, FW_EN, ARG, TR, MATH, GK_TERMS, ENG, BN, MOCK

উদাহরণ:
```bash
python3 engine/so.py log MATH 10 "লাভ-ক্ষতি, ২টি ভুল"
python3 engine/so.py log FW_BN 1 "মূল্যস্ফীতি, ২৬০ শব্দ, ১৮ মিনিট"
```
